# Flink SQL

SQL 层：从一条 SQL 文本到执行计划。

## 主题清单

| 主题 | 关注点 | 状态 |
|---|---|---|
| SQL 解析 | Calcite Parser、SqlNode、DDL/DML 解析 | ⬜ 待开始 |
| SQL 优化器 | 逻辑计划、规则优化、代价模型、物理计划生成 | ⬜ 待开始 |
| Join 算子 | Regular / Interval / Lookup Join、双流 Join 的状态与水位线 | ⬜ 待开始 |
| 外部集成 | Table Connector、Catalog、格式（JSON/Avro/Parquet） | ⬜ 待开始 |

> 每个主题一个子目录，笔记写进对应目录即可。
